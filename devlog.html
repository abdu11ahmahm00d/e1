What Was Implemented

Set up the Vite + React + TypeScript scaffold with pnpm create vite. Added React Router v7 in framework mode for SSR — the pseudo-SSG approach we'd been using (pre-build script + client-rendered React) meant crawlers that don't execute JS saw an empty <div id="root"></div>. Framework mode with prerender: true produces real HTML at build time, fixing SEO without a separate SSR server.

The gotcha: Vite's build.rollupOptions needed manual config to tree-shake the server runtime from the client bundle. Without it, the client build included ~40KB of dead code from @react-router/express.

Key Learnings

  • React Router v7 prerender mode doesn't handle dynamic routes with params — had to add a prerender config to list all paths explicitly
  • pnpm peer dependency resolution is stricter than npm — had to add --shamefully-hoist for some legacy deps
